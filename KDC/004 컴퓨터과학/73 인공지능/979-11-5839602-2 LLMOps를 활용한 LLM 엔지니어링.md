## 책 소개 요약

《LLMOps를 활용한 LLM 엔지니어링》은 LLM 애플리케이션의 개발, 운영, 평가, 개선 과정을 실무 중심으로 설명하는 LLMOps 가이드다. 단순히 모델을 호출하거나 프롬프트를 작성하는 수준을 넘어, LLM을 실제 제품과 서비스에 적용할 때 반복적으로 마주치는 문제를 어떻게 관리하고 개선할지에 초점을 맞춘다.

책은 고객 문의 분류 애플리케이션과 RAG 기반 보험 챗봇을 실습 사례로 삼아, 랭체인, 스트림릿, 파인콘, SQLite 같은 도구를 활용하는 흐름을 다룬다. 프롬프트 버저닝, 데이터셋 관리, 성능 평가 자동화, 합성 데이터셋 생성 등 LLM 애플리케이션 운영에 필요한 기능을 직접 구현해 보도록 구성돼 있다.

또한 LLMOps와 MLOps의 차이, 클로즈드/오픈소스 모델 선택 기준, RAG 평가, 모니터링, 캐싱, 모델 경량화, 체이닝과 에이전트 지원까지 이어지는 지속적 개선 전략을 함께 다뤄, LLM 기반 서비스를 운영 단계까지 가져가려는 개발자와 실무자에게 잘 맞는다.
