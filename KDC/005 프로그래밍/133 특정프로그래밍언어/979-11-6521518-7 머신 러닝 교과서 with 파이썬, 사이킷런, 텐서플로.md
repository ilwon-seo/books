## 책 소개 요약

《머신 러닝 교과서 with 파이썬, 사이킷런, 텐서플로》는 머신 러닝과 딥러닝의 핵심 이론을 파이썬 실습과 함께 체계적으로 다루는 대형 레퍼런스형 교재다. 분류·회귀·군집·차원 축소 같은 전통 머신 러닝 주제부터 인공 신경망, CNN, RNN, GAN, 강화 학습까지 폭넓게 연결해 학습할 수 있다.

초반부는 데이터 전처리, 모델 선택, 성능 평가, 하이퍼파라미터 튜닝, 앙상블 학습 등 실무에서 가장 자주 쓰는 머신 러닝 워크플로를 다룬다. 중반 이후에는 텐서플로 2 기반 신경망 구현과 이미지·텍스트·시계열 문제를 포함한 딥러닝 실습으로 확장된다.

이론 설명과 코드 구현의 균형이 좋아서, 단순 API 사용법을 넘어 알고리즘의 원리와 적용 맥락까지 함께 익히고 싶은 독자에게 특히 적합하다.

## 목차

### 1장. 컴퓨터는 데이터에서 배운다
- 머신 러닝의 학습 유형(지도/비지도/강화)
- 머신 러닝 시스템 구축 로드맵
- 파이썬 머신 러닝 환경 구성

### 2장. 간단한 분류 알고리즘 훈련
- 퍼셉트론과 학습 규칙
- 아달린(Adaline)과 경사 하강법
- 확률적 경사 하강법

### 3장. 사이킷런을 타고 떠나는 머신 러닝 분류 모델 투어
- 로지스틱 회귀
- 서포트 벡터 머신(SVM)
- 결정 트리, 랜덤 포레스트, k-최근접 이웃

### 4장. 좋은 훈련 데이터셋 만들기: 데이터 전처리
- 누락 데이터 처리
- 범주형 데이터 인코딩
- 특성 스케일링과 특성 선택

### 5장. 차원 축소를 사용한 데이터 압축
- PCA(주성분 분석)
- LDA(선형 판별 분석)
- 커널 PCA

### 6장. 모델 평가와 하이퍼파라미터 튜닝의 모범 사례
- 파이프라인 구성
- 교차 검증, 학습 곡선/검증 곡선
- 그리드 서치와 성능 지표

### 7장. 다양한 모델을 결합한 앙상블 학습
- 다수결 투표 앙상블
- 배깅
- 에이다부스트

### 8장. 감성 분석에 머신 러닝 적용
- 텍스트 전처리와 BoW, TF-IDF
- 문서 분류 모델 훈련
- 토픽 모델링(LDA)

### 9장. 웹 애플리케이션에 머신 러닝 모델 내장
- 모델 직렬화
- SQLite 연동
- Flask 기반 배포

### 10장. 회귀 분석으로 연속적 타깃 변수 예측
- 선형/다중 회귀
- 다항 회귀
- 랜덤 포레스트 회귀

### 11장. 레이블되지 않은 데이터 다루기: 군집 분석
- k-평균
- 계층 군집
- DBSCAN

### 12장. 다층 인공 신경망을 밑바닥부터 구현
- 다층 퍼셉트론 구조
- 역전파 알고리즘
- MNIST 분류 실습

### 13장. 텐서플로를 사용한 신경망 훈련
- 텐서와 데이터셋 API
- `tf.keras` 모델 구성/훈련/평가
- 활성화 함수와 다중 분류

### 14장. 텐서플로 구조 자세히 알아보기
- 계산 그래프 개념
- 자동 미분(GradientTape)
- 커스텀 모델/레이어 구성

### 15장. 심층 합성곱 신경망으로 이미지 분류
- CNN 핵심 구성 요소
- 텐서플로 CNN 구현
- 얼굴 이미지 분류 실습

### 16장. 순환 신경망으로 순차 데이터 모델링
- RNN/LSTM
- IMDb 감성 분석
- 문자 단위 언어 모델과 트랜스포머 개요

### 17장. 새로운 데이터 합성을 위한 생성적 적대 신경망
- GAN 기본 구조
- DCGAN, WGAN-GP
- 모드 붕괴와 응용

### 18장. 강화 학습으로 복잡한 환경에서 의사 결정
- 마르코프 결정 과정(MDP)
- 동적 계획법/몬테카를로/시간차 학습
- OpenAI Gym 기반 Q-러닝

### 부록 A. 윈도에 아나콘다, 사이킷런, 텐서플로 설치
- 아나콘다 설치
- 사이킷런/텐서플로 설치
- 예제 노트북 실행 및 코랩 활용
