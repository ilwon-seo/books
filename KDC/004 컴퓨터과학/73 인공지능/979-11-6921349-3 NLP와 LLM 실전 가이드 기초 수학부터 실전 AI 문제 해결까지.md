## 책 소개 요약

이 책은 자연어 처리(NLP)를 전통적 기법부터 최신 LLM 응용까지 하나의 흐름으로 연결해 설명하는 실전형 입문·중급서다. 선형대수, 확률, 통계, 최적화 같은 기초 수학을 바탕으로 머신러닝과 딥러닝 모델을 이해하게 한 뒤, 텍스트 전처리, 분류, 시퀀스 모델링, 트랜스포머, 생성형 AI, 프롬프트 엔지니어링, RAG, LangChain, 에이전트까지 단계적으로 다룬다. 특히 “기초 수학 → 전통 NLP → 딥러닝 NLP → LLM 응용”으로 이어지는 구조가 분명해서, 실습과 개념을 함께 익히기에 적합한 책이다.

번역서는 한빛미디어에서 **「NLP와 LLM 실전 가이드: 기초 수학부터 실전 AI 문제 해결까지」**라는 제목으로 출간되었고, 원서는 Packt에서 **[*Mastering NLP from Foundations to LLMs*](https://www.amazon.com/Mastering-NLP-Foundations-LLMs-rule-based/dp/1804619183)**라는 제목으로 출간되었다.

## 이 책의 특징

- NLP와 LLM 학습에 필요한 **수학·통계 기초**부터 설명
- 전통적인 **규칙 기반/머신러닝 기반 NLP**와 최신 **LLM 기반 접근**을 함께 다룸
- **Python 코드 예제** 중심으로 실습 가능
- 최신 실무 주제인 **프롬프트 엔지니어링, RAG, LangChain, AI 에이전트**까지 포함
- 이론만이 아니라 **실제 비즈니스 문제 해결 흐름**을 염두에 두고 구성됨
